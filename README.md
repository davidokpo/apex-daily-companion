# Apex Daily Companion

A mobile-first daily companion web app built for spiritual growth, deep work, and physical vitality ("Atomic Mode").

## Features
- **Live Window & Dynamic Sky Hero**: Automatically detects your current schedule block and shifts sky ambiance (`dawn`, `day`, `dusk`, `night`).
- **Dynamic Slot Swap**: Swap any modular block on the fly without breaking momentum, saved per-day in `localStorage`.
- **Non-Negotiables Checklist & Mascot Ring**: Track daily anchors with animated progress ring, mascot reactions, and custom goals.
- **Weekly Blueprint & `.ICS` Export**: Inspect any day's schedule, export to your phone calendar (`.ics`), and view Samsung/Google Phone Routine triggers.
- **Installable PWA**: Add to Home Screen on iOS or Android for a full-screen native-like experience.

## Deploying on Vercel
1. Go to [Vercel](https://vercel.com/new) and import this repository (`apex-daily-companion`).
2. Leave the **Framework Preset** as **Other** (zero build step needed).
3. Click **Deploy** and open the generated `.vercel.app` URL on your phone.
